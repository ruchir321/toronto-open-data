# Business Opportunity Analysis

This project analyzes business opportunities in Toronto by combining data on business licenses, neighborhood profiles, demographics, and economic indicators. It aims to identify potential gaps or saturated markets in specific neighborhoods.

## Code Used
- `app.py`
- `process_data.py`
- `main.py`
- `download_data.py`

## Data Used
- `business_licenses.csv`
- `neighborhood_profiles.csv`
- `neighborhood_stats.csv`
- `wellbeing_economics.xlsx`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python app.py
   ```
