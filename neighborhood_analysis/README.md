# Neighborhood Analysis

Comprehensive analysis of Toronto neighborhoods, integrating crime rates, cycling networks, parks, and places of interest to provide a holistic view of community safety and amenities.

## Code Used
- `analyze_neighborhood.py`

## Data Used
- `neighbourhood-crime-rates-4326.csv`
- `cycling-network-4326.geojson`
- `parks-and-recreation-facilities-2952.geojson`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python analyze_neighborhood.py
   ```
