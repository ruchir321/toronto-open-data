# Toronto Island Park Analysis

Analysis of ferry ticket counts and visitor trends for Toronto Island Park, including forecasting models.

## Code Used
- `forecasting.ipynb`
- `preprocessing.ipynb`
- `run_analysis.py`
- `toronto_island_ferry_showcase.ipynb`

## Data Used
- `toronto-island-ferry-ticket-counts.csv`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python run_analysis.py
   ```
