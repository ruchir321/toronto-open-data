# Rainfall Data Analysis

Analyzes precipitation data from Toronto's rain gauges. Includes a Streamlit dashboard to visualize rainfall patterns, total accumulation, and extreme weather events.

## Code Used
- `rainfall_app.py`
- `analyze_rain.py`
- `precipitation_analysis.ipynb`

## Data Used
- `precipitation-data-2024.csv`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python rainfall_app.py
   ```
