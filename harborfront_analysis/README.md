# Harborfront Area Analysis

Focused analysis on the Harborfront neighborhood, including food safety (Dinesafe) and other local metrics.

## Code Used
- `analyze_harborfront.py`
- `app.py`
- `data_loader.py`
- `main.py`

## Data Used
- `dinesafe.json`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python analyze_harborfront.py
   ```
