# Climate Change Analysis

A dashboard and analysis toolkit for visualizing renewable energy installations on City of Toronto buildings. It helps track progress towards climate goals.

## Code Used
- `dashboard.py`
- `find_closest.py`
- `main.py`

## Data Used
- `renewable_energy.xlsx`
- `renewable_energy_shp/`

## How to Run
1. **Initialize Environment**:
   ```bash
   uv init
   uv sync
   ```
2. **Run Code**:
   Navigate to the `code/` directory and run the scripts or notebooks.
   ```bash
   cd code
   # Example:
   python dashboard.py
   ```
